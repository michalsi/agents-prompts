# VS Code + Copilot CLI

This folder contains examples and configuration samples for integrating prompts and agents with VS Code and GitHub Copilot CLI.

## Contents

- **settings.sample.json**: example VS Code settings for Copilot workflows
- Space for snippets, tasks, or launch configs that reference prompts

## Integration patterns

**VS Code snippets**: Create snippets that insert prompts from `prompts/` into chat or inline suggestions.

**Copilot CLI**: Pass prompt files directly to CLI commands or combine agent definitions with prompts in scripts.

**Modular approach**: Keep agents and prompts separate. Combine them at runtime via simple scripts or tooling.
